# 云枢开放平台 用户接口 v2

## 鉴权方式

所有用户接口采用 Bearer Token 鉴权。请求头携带 `Authorization: Bearer <access_token>`。Access Token 有效期 2 小时，过期后使用 Refresh Token 换新，Refresh Token 有效期 30 天且一次性使用。

## 获取用户信息

```
GET /v2/users/{userId}
```

返回指定用户的公开信息。路径参数 `userId` 为用户唯一标识。响应包含 `id`、`nickname`、`avatar`、`created_at` 四个字段。

## 批量查询用户

```
GET /v2/users?ids=u1,u2,u3
```

批量查询用户信息。`ids` 参数以逗号分隔，单次最多传入 50 个用户 ID。响应为用户数组，顺序与传入顺序一致。

## 分页参数

列表类接口统一支持分页：`page` 从 1 开始，`limit` 默认 20，最大允许 100。超过 100 的 limit 会被截断为 100 并在响应头 `X-Pagination-Limit` 中返回实际生效值。分页响应体携带 `total` 字段表示总条数。

## 限流说明

用户接口限流为每分钟 60 次请求。超限返回 HTTP 429，响应头 `Retry-After` 指示等待秒数。建议客户端实现指数退避重试。
