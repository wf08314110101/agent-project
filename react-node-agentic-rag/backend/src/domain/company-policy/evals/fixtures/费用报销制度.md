# 云枢科技费用报销制度

第1条 为规范日常费用报销流程，制定本制度。

第2条 报销须通过 OA 系统线上提交，纸质单据随后归档；口头申请一律无效。

第3条 报销凭证必须为合规发票，抬头须为公司全称，税号正确。

第4条 审批权限：单笔金额超过 5000 元的报销需财务总监会签；超过 50000 元的需总经理审批。

第5条 时效要求：发票开具日期超过 90 天的不予报销；报销单自提交之日起，财务 10 个工作日内完成打款。

第6条 月度截止：每月 25 日为当月报销受理截止日，25 日后提交的单据顺延至下月处理。

第7条 电子发票须通过税务平台验真，查验截图作为附件上传；一张发票只能报销一次，系统查重。

第8条 本制度自 2025-06-01 起施行。
