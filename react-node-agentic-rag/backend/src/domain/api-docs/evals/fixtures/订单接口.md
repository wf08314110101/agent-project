# 云枢开放平台 订单接口 v2

## 创建订单

```
POST /v2/orders
```

创建订单。请求体必填字段：`sku_id`（商品标识）、`quantity`（数量，1-999）。可选字段 `coupon_id` 指定优惠券。创建成功返回 HTTP 201 与订单号 `order_no`。

## 查询订单状态

```
GET /v2/orders/{orderNo}
```

查询单笔订单。订单状态机为：`created` → `paid` → `shipped` → `completed`，任一状态可流转到 `cancelled`。状态查询接口不缓存，实时返回。

## 订单超时机制

未支付订单的自动关闭时间为下单后 30 分钟。超时后订单状态变更为 `cancelled`，原因是 `timeout`。支付回调到达时若订单已关闭，系统自动原路退款，退款到账周期为 1-3 个工作日。

## 订单搜索

```
GET /v2/orders?status=paid&begin=2026-01-01&end=2026-01-31
```

按状态与时间范围搜索订单。时间格式为 `YYYY-MM-DD`，范围为闭区间。单页返回条数遵循全局分页规则，最大 100 条。

## 幂等性

创建订单支持幂等：请求头携带 `Idempotency-Key`，同一 key 在 24 小时内重复请求返回首次创建的结果，不产生重复订单。key 长度上限为 64 字符。
