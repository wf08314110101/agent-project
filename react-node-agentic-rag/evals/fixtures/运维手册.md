# 运维手册

## 服务部署清单

生产环境使用 docker compose 编排四个服务：qdrant 向量数据库监听 6333 端口，phoenix 观测面板监听 6006 端口，backend 后端服务对内 8787 端口由 nginx 反代，frontend 静态资源由 nginx 直接服务。全部服务配置了健康检查与启动依赖，qdrant 就绪后 backend 才启动。

## 限流参数

网关层限流分三档：全局每分钟 120 次请求，对话接口每分钟 20 次，登录接口每分钟 10 次。超限返回 429 状态码。限流按 IP 统计，生产接入网关后建议改为按用户标识统计。

## 日志与排障

后端日志输出到 logs/backend.log，前端开发日志在 logs/frontend.log。SSE 流式接口排障时优先检查 nginx 是否关闭了 proxy_buffering，否则事件会被缓冲成一次性输出。

## 备份策略

数据资产包括两部分：qdrant 数据卷（向量索引）与 backend/data 目录（SQLite 元数据库与嵌入模型缓存）。备份脚本每日凌晨两点执行，保留最近 7 份，异地同步到对象存储。
