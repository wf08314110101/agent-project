# 云枢科技信息安全管理制度

第1条 为保护公司信息资产安全，制定本制度。

第2条 全体员工须签署保密协议，离职时须归还全部办公设备并注销账号。

第3条 密码策略：办公系统密码长度不得少于 8 位，且每 90 天强制更换一次；禁止多系统共用同一密码。

第4条 办公电脑须开启锁屏（离开工位 5 分钟内自动锁定），并安装公司统一的终端防护软件。

第5条 USB 存储设备默认禁用，确因业务需要使用的须 IT 部审批并登记。

第6条 对外发送含敏感信息的文件须加密压缩，密码经 IM 单独告知。

第7条 生产数据导出须填写申请单，导出记录保留 180 天备查。

第8条 事件报告：发现泄密或疑似泄密事件，须在 24 小时内报告信息安全组，不得自行处置或隐瞒。

第9条 本制度自 2025-01-01 起施行。
