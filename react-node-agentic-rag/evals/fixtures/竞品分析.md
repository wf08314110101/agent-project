# 竞品分析报告 2026 Q2

## 市场格局

智能知识管理赛道目前三家头部：竞品 A 主打检索增强与企业微信集成，月活跃用户 120 万，报价每席位每年 980 元；竞品 B 主打多模态文档理解，支持扫描件与图表解析，月活跃用户 80 万，报价每席位每年 1280 元；竞品 C 为开源方案，免费但需自行运维，月活跃用户约 35 万。

## 功能对比

检索质量维度：竞品 A 使用单路向量检索，竞品 B 支持向量加关键词的混合检索，本产品的混合检索额外带相关性评估与查询改写。多模态维度：仅竞品 B 支持图片型 PDF 的 OCR 解析。私有化部署：本产品与竞品 C 支持，竞品 A/B 仅 SaaS。

## 定价策略建议

建议本产品定价锚定竞品 A 的 90%（约 880 元每席位每年），以功能差异（CRAG 评估链路）支撑溢价理由，同时在 50 席位以上提供阶梯折扣对冲竞品 B 的企业客户争夺。
