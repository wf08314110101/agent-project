# 云枢开放平台 Webhook 回调接口（已废弃 v1，请迁移 v2）

> 本文档描述的 `/v1/webhooks` 端点已进入废弃周期，仅做安全修复，不再新增功能。新接入请使用 v2 端点。

## 事件订阅（v1，已废弃）

```
POST /v1/webhooks/subscriptions
```

v1 事件订阅仅支持 `order.paid` 与 `order.cancelled` 两类事件。v1 回调超时时间为 5 秒。该端点将于 2027 年 1 月 1 日下线。

## 事件订阅（v2，推荐）

```
POST /v2/webhooks/subscriptions
```

v2 订阅支持全部 12 类事件，包括 `order.paid`、`order.refunded`、`user.signup` 等。v2 相比 v1 的关键升级：回调超时从 5 秒放宽到 10 秒，并支持事件批量投递（单次最多 20 条事件）。

## 回调重试策略

回调失败（非 2xx 响应或超时）后按固定间隔重试：最多重试 3 次，每次间隔 5 分钟。3 次重试均失败后进入死信队列，可在控制台手动重投。死信队列中的事件保留 7 天。

## 回调签名校验

每个回调请求携带 `X-Signature` 头，签名算法为 HMAC-SHA256，密钥为创建订阅时返回的 `secret`。校验方式：对请求体原文计算 HMAC-SHA256 并与 `X-Signature` 比对。签名不一致必须返回 HTTP 403 拒绝处理。时间戳偏差超过 5 分钟的请求视为重放攻击，直接拒绝。
