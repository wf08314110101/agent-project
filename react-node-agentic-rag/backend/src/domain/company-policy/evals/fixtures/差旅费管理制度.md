# 云枢科技差旅费管理制度

第1条 为规范差旅开支，控制成本，制定本制度。

第2条 员工出差须提前在 OA 系统提交出差申请，未经批准的差旅费用不予报销。

第3条 交通标准：高铁一律二等座；乘坐飞机须为单程 1200 公里以上航线，且需部门总监审批，仅限经济舱。

第4条 住宿标准：一线城市（北京/上海/广州/深圳）每晚 600 元，其他城市每晚 400 元；同性别同事出差原则上合住。

第5条 补贴标准：餐补 100 元/天；市内交通实报实销，上限 80 元/天。

第6条 报销时限：出差返回后 5 个工作日内提交报销单，逾期系统自动关闭入口，特殊情况须经财务总监批准。

第7条 本制度自 2025-10-01 起施行，原《出差管理办法》同时废止。
